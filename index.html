        ☁️ 数据同步（GitHub Gist）

        首次使用：在 GitHub 生成一个 token（勾选 gist 权限），填入后点击"同步到云端"。系统会自动创建 Gist。之后在另一设备填入相同 token，点击"从云端同步"即可。

        📊 统计栏配置

        选择要在统计栏显示的项目。数字字段可求和/平均，其他字段可计数。

        📐 公式使用说明

        📖 基本规则

        • 支持加(+)、减(-)、乘(*)、除(/)和括号()
        • 可以用中文名或英文名引用字段，效果相同
        • 公式字段为只读，自动根据其他字段计算

        🔢 可用函数

        函数说明示例
        round(x, n)四舍五入到 n 位小数round(3.1415, 2) = 3.14
        round(x)四舍五入到整数round(3.6) = 4
        abs(x)绝对值abs(-5) = 5
        ceil(x)向上取整ceil(3.1) = 4
        floor(x)向下取整floor(3.9) = 3

        📋 可用字段

        💡 实用示例

        💸 利润（价格-成本）：价格 - 成本
        💰 含税金额：round(价格 + 价格 * 税率, 2)
        🎯 打折价（8折）：round(价格 * 0.8, 2)
        📊 利润率：round((价格 - 成本) / 价格 * 100, 2)
        🔀 按字段分组计算：在"字段设置"里点公式字段旁的分组按钮，可按某个字段（如"来源"）的不同值各配一套公式，列表、统计、批量计算都会自动按分组计算。
